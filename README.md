# 出账日 · CheckList

<img src="Resources/Brand/logo.png" width="96" height="96" alt="出账日 Logo">

一个常驻 macOS 菜单栏的还款提醒工具。记录信用卡与贷款账单，查看待还总额，并在还款日收到提醒。

## 功能

- 记录账单名称、类型、金额及还款日，按到期日查看待还账单；可随时编辑，删除后也能立即撤销。
- 待还列表悬停即可快速还款，右键可还款、进入下一期、稍后提醒、免打扰、编辑或删除；也可用方向键选择、空格还款、回车打开、⌫ 删除。
- 菜单栏用账单日历线条标显示待还负债，金额为负数，并显示最近账单的剩余天数／小时或逾期状态；可快捷查看最近四笔账单，也可只显示倒计时或仅图标。
- 到期显示玻璃提醒卡，支持已经还款、稍后提醒（1 小时后／今晚／明天）、不再提醒和收起；贷款可直接进入「下一期」，卡上会说明后面还有几笔待处理。
- 还款、免打扰、下一期和删除都会在提示条上提供「撤销」。
- 贷款「下一期」一次完成本期还款并复制为下个月的账单，短月份取月末，并在后续月份恢复原日号。
- 信用卡可「复制为下月账单」：带入名称和下月还款日，金额留空，填好再保存。
- 已还清记录与累计已还总额、撤销还款、单笔提醒开关与删除确认；记录中显示实际还款日期。
- 每日提醒时间和提示音设置，启动及唤醒后补查；尚未开启系统通知时，侧栏和账本页会提示开启。
- SwiftData 本地账本，无需账号或服务端；金额以整数分保存。
- 最小 760 × 520 窗口，可纵向拉伸并记住尺寸；macOS 26 及以上采用 Liquid Glass，旧系统采用 Material。
- 首次使用跟随系统外观，也可在「提醒设置」右边切换明／暗主题并记住选择；输入框、文字、到期标签及提醒卡统一适配。

## 安装与使用

从 GitHub Releases 下载 DMG，将「出账日.app」拖入 Applications 后打开。

**系统要求：** macOS 14 或更高版本。当前下载包为 Apple Silicon（arm64）。

在「提醒设置」允许系统通知后，退出应用也可以收到已排程的通知。关闭主窗口会继续在菜单栏运行；从弹窗底部或应用菜单选择「退出」才会结束进程。

本次发布使用 `Moa Local Development Code Signing` 本地自签证书，已启用 hardened runtime，尚未使用 Apple Developer ID 签名或 Apple 公证。下载后可能提示无法验证开发者，包括曾经手动放行过旧版的 Mac；请通过系统提供的确认打开方式处理。

固定使用同一张本地证书不会自动通过 Gatekeeper；`codesign --verify` 验证通过也不代表下载后的安全评估通过。当前打包脚本仅签名和校验，未提交 Apple 公证。要改善公开下载后的首次打开体验，需要使用 Developer ID Application 证书、可信时间戳和 Apple 公证，并附加公证票据。

## 提醒规则

- 默认在还款日 09:00 提醒，可在设置中修改。
- 已过提醒时间才添加当天到期的账单，会立即提醒。
- 同一账单每天自动提醒一次；未还款则次日继续提醒。
- 稍后提醒可选 1 小时后、今晚 20:00 或明天的提醒时间；关闭提醒只影响该笔账单。
- 提醒卡上的「收起」只关掉当前这张卡，下一笔已到期的账单会接着弹出；该账单当天不会再弹。
- 还款或删除后取消相关提醒；旧通知不会覆盖新的还款、静音或稍后状态。
- 贷款选择「下一期」后，原账单归入已还清，下期复制名称、金额和提醒开关，按新的还款日期提醒。
- 应用运行期间每 20 秒补查，并在唤醒、日期或时区变化后补查。

系统通知采用滚动排程：先为每笔账单保留下一次提醒，再补充随后七天的每日提醒，合计最多 60 条。退出应用后只能投递已经排程的通知，重新启动后会续排。长期使用建议保持菜单栏应用运行。系统通知会受权限、专注模式与系统调度影响。

菜单栏倒计时以还款日当天结束为截止；不少于 24 小时按完整的 24 小时向下取整显示天数（例如剩余 47 小时显示「剩 1 天」），不足 24 小时按小时向上取整。关闭单笔提醒不会移除其倒计时；有逾期账单时优先显示最早一笔的逾期天数。

## 隐私与数据

账单只保存在本机：

- 正式账本：`~/Library/Application Support/CheckList/`
- 演示账本：`~/Library/Application Support/CheckList-Demo/`

还款日保存为年月日，按本地日历解析；切换时区不会将原始还款日期改成另一天。读取失败时会保留已有账本并显示错误。

演示模式具有独立账本与设置，不读取、清除或修改正式系统通知队列。原始 Figma Make 导出、设计聊天截图、验收日志及本地数据库不包含在仓库或安装包中。

## 开发

需要完整 Xcode 26 或更新版本，以及 Swift 6.2 或更新版本的编译器。可以用 Xcode 打开 `Package.swift`。

```sh
# 使用本机已有的 Moa 开发证书构建
./scripts/build.sh
open build/出账日.app

# 没有该证书时，显式选择 ad-hoc 签名
CODE_SIGN_IDENTITY=- ./scripts/build.sh

# 独立演示模式；切换前先退出正在运行的实例
open build/出账日.app --args --demo

# 严格并发与警告检查
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift test -Xswiftc -strict-concurrency=complete -Xswiftc -warnings-as-errors

# 生成并验证 DMG 与 SHA-256 文件
./scripts/package-dmg.sh
```

可通过 `CODE_SIGN_IDENTITY` 指定其他已有证书。脚本不会创建证书，也不会在指定证书缺失时自动改用其他签名。

构建脚本默认使用 `/Applications/Xcode.app`，也可设置 `DEVELOPER_DIR`。使用 `CHECKLIST_DATA_DIR` 可以指定独立验收账本，该模式不会操作正式系统通知队列。安装包输出到 `release/`，可用 `CHECKLIST_RELEASE_DIR` 修改输出目录。

在独立验收账本模式下，可设置 `CHECKLIST_PREVIEW_APPEARANCE=light` 或 `dark` 指定启动外观；此设置只影响该预览进程。正常使用首次跟随系统，主动切换后使用已保存的偏好。演示／验收模式的偏好与正式模式隔离。
