# 0.2.0 需求与验收

日期：2026-11-04。范围：主题切换、菜单栏倒计时、贷款下一期、累计已还金额。

## 1. 明／暗主题按钮

- 在主窗口侧栏底部「提醒设置」右边显示主题按钮，所有页面均可使用。
- 浅色时显示月亮，点击切换深色；深色时显示太阳，点击切换浅色。
- 鼠标提示与辅助功能名称明确说明切换后的主题。
- 立即同步主窗口、菜单栏弹窗、设置窗口和到期提醒卡。
- 首次使用跟随系统；主动选择后保存偏好，重启继续使用选定主题。
- 演示／独立验收模式的偏好与正式模式隔离。

## 2. 菜单栏倒计时

- 保留图标和待还负债金额，在右侧增加 `· 剩 N 天` 或 `· 剩 N 小时`。
- 从所有未还账单中选最早还款日；相同日期沿用账单创建时间排序。
- 已还款账单不参与；关闭提醒、稍后提醒的账单仍参与。
- 现有账单没有具体时分，统一以本地还款日当天结束（次日零点）为截止。
- 剩余时间不少于 24 小时，按 24 小时一天向上取整；不足 24 小时，按小时向上取整。不足一小时显示 `剩 1 小时`。
- 已经过还款日，显示 `逾期 N 天`，按本地日历日计算，优先展示最早的逾期账单。
- 没有待还账单时，显示 `¥0 · 已还清`。
- 提示文字包含最近账单名称、到期日和截止口径。
- 增删账单、还款、撤销后立即刷新；运行期间每 20 秒刷新，并响应唤醒、日期、时钟与时区变化。

## 3. 贷款「下一期」

- 仅未还款的贷款账单显示入口，位置在详情操作区和应用内提醒卡；信用卡与已还清详情不显示。
- 点击后将本期设为已还款、记录还款时间，同时创建一笔未还的下期贷款。
- 完整复制现有可填写资料：名称、类型、金额；金额仍以整数分保存。
- 保留单笔提醒开关；新账单清空还款时间、稍后提醒和已投递记录，并使用新的账单 ID 与提醒代次。
- 日期以本期原还款日期为基准加一个月，与实际点击／补还时间无关。
- 下个月不存在原日号时取月末，并持久保存原日号。例如 `2027-01-31 → 2027-02-28 → 2027-03-31`；闰年二月为 29 日。
- 本期还款与下期创建同次保存。失败时两者一起回退，保留原提醒卡和账单状态，可重试。
- 重复点击不重复创建。撤销本期还款后，已有下期仍保留；再次点击「下一期」提示已有下期，避免多建。
- 成功后详情返回待还列表；提醒卡关闭并继续处理其他到期账单；旧通知撤销，下期按新日期排程。
- 当前版本没有任意键值的自定义字段功能，本次复制现有账单的全部可填写字段。

## 4. 已还清金额统计

- 已还清页面顶部使用与待还页面相同的金额组件。
- 标题为「累计已还总额」，展示所有已还清记录的金额总和。
- 沿用人民币符号、千分位、两位小数、大号金额、变化动画、缩放与明暗配色。
- 次行显示 `共 N 笔已还清`；没有已还账单时仍显示 `¥0.00`。
- 还款、下一期、撤销还款、删除记录后同步更新。

## 验证范围

- 金额精度与统计、贷款复制、跨年／闰年／月底连续续期、重启持久化。
- 防重复生成、保存失败回退、提醒卡保留与重试、旧提醒撤销和新提醒排程。
- 倒计时天／小时边界、到期当天、逾期、空列表、静音账单、夏令时。
- 主题偏好默认值、切换、保存与重载；真实窗口的明暗切换、按钮布局和操作流程。
- 使用修改前 0.1.2 的实际模型生成独立旧账本，再由 0.2.0 打开、续期并重开验证。
- 使用完整 Xcode，运行严格并发和警告视为错误的测试与应用构建。
