# 出账日 0.1.2

本次更新调整菜单栏展示：用产品标志的线条图标替换铃铛，待还金额改为负数，并去掉金额后的红点。

- 菜单栏左侧改为账单日历线条标，包含环扣、账单页、还款勾和折角。
- 待还负债显示为负数，例如 −¥29,470；全部还清时显示 ¥0。
- 去掉到期或逾期时显示在金额后面的红点。

**系统要求：** macOS 14 或更高版本，Apple Silicon Mac。

**升级：** 先退出正在运行的出账日，再用 DMG 中的「出账日.app」替换 Applications 中的旧版。已有账本、提醒规则和存储位置保持兼容。

**签名说明：** 使用 `Moa Local Development Code Signing` 本地自签证书，已启用 hardened runtime；不是 Apple Developer ID 签名，也未经过 Apple 公证。其他 Mac 可能提示无法验证开发者，需要通过系统提供的方式确认打开。

**提醒说明：** 系统通知需要用户允许，仍会受专注模式和系统调度影响。关闭主窗口后应用继续常驻菜单栏；退出应用仅能接收已排程的提醒。
