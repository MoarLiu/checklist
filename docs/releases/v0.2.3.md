# 出账日 0.2.3

2026 年 11 月 20 日，构建号 7。

本次新增借款账单与侧栏分类，支持记录贷款期数，并改进提醒与界面对比度。

## 新增与改进

- 「记一笔」新增「借款」，填写借款人、借款金额和承诺还款日期。借款仍显示在「待还账单」，并可在承诺日期提醒；金额不计入主页与菜单栏的待还总额。
- 左侧新增「信用卡账单」「贷款账单」和「借款账单」，分别显示各类型未还记录与小计。已经还款的账单统一归入「已还清」。
- 贷款可记录当前期数和全部期数，账单列表、详情页、编辑预览和到期提醒卡都显示「第 X / Y 期」。
- 「下一期」生成新账单时自动把当前期数加一；到最后一期后不再显示入口，也不会再生成超期账单。
- 新建贷款，或编辑一笔没有期数资料的老贷款时，表单默认「第 1 / 12 期」，两个输入框都可以修改；改成信用卡或借款时会清空贷款期数。
- 保存失败时，期数和金额、日期一起回退，账单保持原样。
- 提高明暗外观中的文字、卡片与主按钮对比度。

## 修复

- 撤销一笔已生成下一期的贷款还款时，提示「下一期账单仍保留」：下期账单按设计保留，但用户不会再误以为总额算错了。
- 系统通知被关闭时，「打开系统设置」直接跳到本应用的通知设置面板，不再只打开系统设置首页。
- 只在菜单栏运行时，保存失败不会再毫无反馈：弹窗里会显示原因，并可跳到账本处理。
- 侧栏切换页面时清除键盘选中的行，避免高亮停在上一个列表的某一行。
- 提醒时间在夏令时跳过整点或整日的极少数时区下不再强制解包日历结果。
- 金额格式化改为复用一个格式化器，列表滚动和大号金额的计数动画不再反复创建。

## 安装与升级

支持 macOS 14 或更高版本，本次下载包适用于 Apple Silicon Mac。

升级前先退出正在运行的出账日，再用 DMG 中的「出账日.app」替换 Applications 中的旧版。应用会读取现有的本地 SwiftData 账本，新增的期数字段对旧账本可迁移，原有金额、日期和还款状态不变。

发布包使用 `Moa Local Development Code Signing` 本地自签证书，并启用 hardened runtime。Apple Developer ID 签名和 Apple 公证尚未提供，下载后可能需要在系统「隐私与安全性」中确认打开。

系统通知需要用户允许，并受专注模式和系统调度影响。关闭主窗口后应用继续常驻菜单栏，退出应用后只能接收已排程的提醒。
