# 出账日 0.1.0

首个 macOS 原生版本，帮助你在菜单栏管理信用卡和贷款的还款日。

- 记录账单金额、名称与还款日期，自动汇总待还总额。
- 查看今天到期、即将到期和逾期账单。
- 支持已还清记录、撤销还款及单笔提醒开关。
- 到期显示玻璃提醒卡，可选择已经还款、稍后一小时或不再提醒。
- 支持系统通知、提示音、自定义每日提醒时间和唤醒补查。
- 账本只保存在本机，无需账号。
- 全新青绿日历 Logo，内置多尺寸 App 图标与侧栏标识。

**系统要求：** macOS 14 或更高版本，Apple Silicon Mac。

**安装：** 下载 DMG 后将「出账日.app」拖入 Applications。

**签名说明：** 本版本使用 `Moa Local Development Code Signing` 本地自签证书，已启用 hardened runtime；不是 Apple Developer ID 签名，也未经过 Apple 公证。其他 Mac 可能提示无法验证开发者，需要通过系统允许的方式确认打开。

**提醒说明：** 在「提醒设置」允许系统通知。关闭主窗口后应用继续在菜单栏运行；退出应用仅能接收已排程的通知。长期使用建议保持应用运行。系统通知会受权限、专注模式和系统调度影响。

循环账单、开机自启、iCloud 同步和 Intel 版本暂未包含在本次发布中。
