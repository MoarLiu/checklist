# 出账日 0.2.2

2026 年 11 月 12 日发布，构建号 6。

本次更新完善账单列表操作、编辑与撤销，并改进到期提醒卡和菜单栏显示。

## 新增与改进

- 列表支持悬停快捷还款、右键操作菜单和键盘导航。方向键选择账单，空格切换还款状态，回车打开详情，删除键发起删除。
- 新增账单编辑和信用卡「复制为下月账单」，复制时带入名称和还款日，金额留空后重新填写。
- 还款、免打扰、下一期和删除操作均提供即时撤销，菜单栏弹窗中也能撤销快捷还款。
- 提醒卡新增收起入口，可选择 1 小时后、今晚或明天再提醒，并显示后续待处理笔数。
- 列表、菜单栏弹窗和提醒卡统一到期状态文案，已还清记录显示实际还款日期，金额输入支持全角数字和小数点。
- 菜单栏可选择「金额与倒计时」「仅倒计时」或「仅图标」，超过四笔待还账单时提供查看全部入口。
- 主窗口支持调整尺寸并记住位置与大小，尚未开启系统通知时提供引导。

## 修复

- 已在此前日期提醒过的逾期账单，会等待当天设定的提醒时间，避免跨日或唤醒后过早弹出。
- 菜单栏弹窗、提醒卡及设置窗口随内容调整尺寸，减少内容被裁切的情况。
- 补充中文本地化，并避免测试初始化时向本机偏好文件写入设置。

## 安装与升级

支持 macOS 14 或更高版本，本次下载包适用于 Apple Silicon Mac。

升级前先退出正在运行的出账日，再用 DMG 中的「出账日.app」替换 Applications 中的旧版。应用会读取现有的本地 SwiftData 账本。

发布包使用 `Moa Local Development Code Signing` 本地自签证书，并启用 hardened runtime。Apple Developer ID 签名和 Apple 公证尚未提供，下载后可能需要在系统「隐私与安全性」中确认打开。

系统通知需要用户允许，并受专注模式和系统调度影响。关闭主窗口后应用继续常驻菜单栏，退出应用后只能接收已排程的提醒。
