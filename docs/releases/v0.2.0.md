# 出账日 0.2.0

本次更新增加明／暗主题切换、菜单栏还款倒计时、贷款「下一期」和累计已还金额统计。

- **明／暗主题按钮：** 位于主窗口「提醒设置」右边，切换后立即同步主窗口、菜单栏弹窗、设置和到期提醒卡，并在重启后保留选择。首次使用仍跟随系统。
- **菜单栏倒计时：** 保留待还负债金额，右侧显示最近一笔待还账单剩余多少天或小时。以还款日当天结束为截止，不少于 24 小时显示天数，不足 24 小时显示小时，均向上取整；有逾期账单时显示最早一笔的逾期天数，全部还清时显示「已还清」。
- **贷款下一期：** 未还贷款的详情和应用内提醒卡新增「下一期」。点击后本期归入已还清，同时复制名称、类型、金额和提醒开关，生成下个月的待还账单。
- **月底续期：** 日期以原还款日顺延一个月，短月份取月末，并在后续月份恢复原日号。例如 `2027-01-31 → 2027-02-28 → 2027-03-31`；本期还款和下期创建一起保存，失败时一起回退，避免重复生成。
- **累计已还总额：** 已还清列表采用与待还列表一致的大号金额统计，显示所有已还金额总和与已还笔数，随还款、撤销和删除更新。

**系统要求：** macOS 14 或更高版本，Apple Silicon Mac。

**升级：** 先退出正在运行的出账日，再用 DMG 中的「出账日.app」替换 Applications 中的旧版。已有账本保持兼容，首次打开会自动补入贷款续期所需字段；金额、还款日期和历史记录保留。

**使用说明：** 「下一期」适用于贷款，需要手动点击；当前支持复制现有账单资料，尚未提供任意自定义字段或自动循环账单。关闭单笔提醒后，该账单仍计入待还金额和倒计时。

**签名说明：** 使用 `Moa Local Development Code Signing` 本地自签证书，已启用 hardened runtime；未使用 Apple Developer ID 签名，也未经过 Apple 公证。固定使用同一张本地证书不会自动通过 Gatekeeper，下载后仍可能需要在系统「隐私与安全性」中确认打开。

**提醒说明：** 系统通知需要用户允许，仍会受专注模式和系统调度影响。关闭主窗口后应用继续常驻菜单栏；退出应用仅能接收已排程的提醒。
